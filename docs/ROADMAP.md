# Roadmap

Roadmap 的目标不是把功能做多，而是逐步验证：

> Watchtower 是否真的减少了主动打开多个 App 的次数。

---

## Phase 0 — Feasibility

**目标：证明数据拿得到。**

这一阶段不急着做漂亮 UI。

### NGA

验证：

- 指定板块新帖；
- 指定板块热帖；
- 登录态；
- 我的回复是否有新回复；
- @；
- 点赞；
- 关注帖子更新。

输出：

- 哪些能力 RSSHub 已覆盖；
- 哪些能力需要自定义 Connector；
- Cookie 是否稳定。

### Bilibili

验证：

- 关注 UP 更新；
- 关注主播直播；
- 关注动态；
- 视频详情与指标；
- 站内关键词搜索。

### 龙空

验证：

- 指定板块更新；
- 热帖/活跃帖；
- 指定帖子新回复。

### 完成标准

至少确认：

- 3 个初始站点都能稳定产生统一 Event；
- 登录凭据方案可接受；
- 不需要通过大规模浏览器自动化才能维持基本功能。

---

## Phase 1 — MVP

**目标：做出一个自己愿意每天打开的页面。**

范围严格控制。

### 数据源

- NGA；
- B站；
- 龙空。

### 首页

固定为三个有限分区：

```text
和我有关   — 回复我 / 点赞我 / @我
关注更新   — 论坛具体帖子 / 关注 UP 新视频 / 关注主播开播
值得看看   — 已添加来源内的主动规则发现或升温内容
```

### 必须有

- 定时刷新；
- 去重；
- 有限数量卡片；
- 点击跳回原站；
- 添加 / 暂停 / 删除 Watchpoint；
- 本地凭据；
- SQLite；
- 基本错误状态展示。

### 明确不做

- App；
- 推送；
- 全网搜索；
- 多用户；
- 阅读历史；
- AI 总结；
- Embedding；
- 无限推荐。

### 完成标准

连续使用至少一段时间后：

- 打开 NGA / B站 / 龙空“只是为了检查一下”的次数明显下降；
- Watchtower 可以在很短时间内回答“现在有没有值得看的东西”。

---

## Phase 2 — Direct Account Events

**目标：补齐“和我有关”。**

这里只包含真正直接作用于账户的事件：

- 我的回复收到新回复；
- @ 我；
- 点赞我。

关注的主播开播、关注对象更新属于“关注更新”，不进入本阶段的“和我有关”。

### 重点

不是展示更多内容，而是提高：

> “如果有事真的发生，我不会错过。”

### 完成标准

用户不再需要因为担心错过账户事件而频繁打开原 App。

---

## Phase 3 — Local Discovery Experiment

**目标：验证站内有限发现。**

第一实验对象：B站 AI 视频。

### 输入

用户主动配置：

```text
标签：AI
关键词：
AI
LLM
Agent
Claude
Gemini
...
```

### 信号

可尝试：

- 发布时间；
- 总播放；
- 播放增长；
- 收藏率；
- 点赞率；
- 投币率；
- 评论增长；
- UP 主历史基线。

### 展示

必须可解释，例如：

```text
为什么出现：
- 匹配 AI 标签
- 过去 2 小时播放增长较快
- 收藏率高
```

### 边界

仍然只在：

> 用户已经添加的 B站

内部发现。

绝不因为 AI 标签自动加入 YouTube / Reddit / 贴吧。

---

## Phase 4 — Connector Expansion

**目标：验证站点接入是否真的模块化。**

候选：

- 贴吧；
- YouTube；
- 其他论坛；
- Generic RSS。

如果新增站点需要大量修改主程序，说明 Connector 边界设计失败，需要先修架构，而不是继续堆站点。

### 完成标准

增加一个结构类似的新论坛，主要修改应集中在：

```text
connectors/<site>/
```

而不是 Core / Dashboard。

---

## Phase 5 — Reliability

只有项目真正长期使用后再考虑。

可能包括：

- Connector 健康检查；
- Cookie 失效提醒；
- 失败重试；
- 缓存策略；
- 站点限流；
- Docker Compose；
- 备份 / 恢复；
- 更完善的 Secrets 管理。

---

## 暂不规划

除非真实使用证明必要，否则不进入 Roadmap：

- 全网兴趣图谱；
- 自动推荐新站点；
- 用户画像；
- 黑盒推荐算法；
- 内容社交；
- 评论；
- 长期阅读历史；
- 全文归档；
- 跨设备阅读同步；
- “每天多刷一点”的增长机制。

Roadmap 可以改变，但这些功能需要比普通功能更高的进入门槛。
